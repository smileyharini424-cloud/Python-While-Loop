# Python While Loop

## Explanation

A `while` loop repeatedly executes a block of code as long as a specified condition remains `True`.

## Problem Statement

Write a Python program that accepts a number from the user and prints all numbers from 1 up to that number using a `while` loop.

## Features

* Accepts a limit from the user
* Uses a `while` loop
* Uses a loop condition
* Prints numbers in sequence

## How It Works

The program starts a counter at `1`. The `while` loop continues as long as the counter is less than or equal to the given limit.

After printing each number, the counter is increased by `1`.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Read the limit from the user.
3. Initialize the counter to `1`.
4. Check the loop condition.
5. Print the counter.
6. Increase the counter.
7. Repeat until the condition becomes false.
8. End the program.
